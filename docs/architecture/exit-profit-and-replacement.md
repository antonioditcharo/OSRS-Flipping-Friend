# Expected exit profit and cancelled-buy recovery

20 October 2026. Delivery state is recorded in HANDOFF and the linked receipt.

The old sidebar's unrealized profit was the last public instant-sale bid after tax minus exact
acquisition cost. It could be positive, but was commonly negative while a profitable limit sale
was waiting. The primary unrealized figure now estimates profit at current unsold sell listings,
then the proven original acquisition target for any observed unlisted remainder. Each portion
shows its quantity, price, after-tax proceeds and source in the tooltip. Missing original targets
stay unknown. Unseen units, personal extras and unfilled buy quantities cannot inflate the figure.
Subset cost uses SaleAccounting.allocateCost once across the covered acquired quantity; current
tax classification must be exact for a single target-profit claim. This is an expected limit-order
result, not guaranteed profit, a new execution or a historical accounting change.

Instant-sale P/L remains separately visible. Portfolio value continues to use public bid estimates;
unknown price coverage and unknown exit coverage have independent acquisition-cost totals. Targets
never fund buys or change risk marks, financial history, loss anchors or canonical holdings. Missing
fresh account/eight-slot proof withdraws both estimates. Legacy response validation remains supported.

Cancelled-buy queues previously returned the first locally eligible remainder. If final companion
authority refused that one, a later eligible remainder could be bypassed by unrelated new buying.
The client now tries each locally eligible saved remainder through final authority, retaining the
original quantity cap. If all are refused, it checks verified acquired partial stock for a supported
exit before unrelated buying. Local funding/limit refusals use that same exit check before the
last-slot reservation. It never sells around a still-working buy, adopts belongings or bypasses
canonical stock, quote, exact-cost or final-sale authority. A refused remainder remains durable.

Accepting a cost-known sale must durably supersede that item's old rebuy promise, including healthy
sales. Failed persistence withdraws the sale and allows retry. A collected buy continuation also
closes on an observed same-item sale with a distinct episode and a first-seen time provably later
than its creation/original buy, no later than now. Older personal listings cannot retire it. This
changes local workflow hints only, with no financial replay or inference that the sale filled.

Verification covers first-refused/later-eligible remainders, final sale authority, exact partial
quantities, last-slot/funding refusal, failed supersession/retry, later versus older sale episodes,
positive target profit with negative instant-sale P/L, exact subset cost, changed listings and real
planned losses, missing targets/quotes, personal extras, risk separation and native panel rendering.
Controlled player cancel/collect/replace or partial-exit/restart acceptance remains required.
